# dsh-sidebar-cards · 左侧边栏卡片化

把 DSH 桌面版左侧栏的「会话浏览区」（`sidebar.workspaces`）替换成 5 张卡片，其余部分（logo / HARNESS、新会话 Ctrl+N、底部设置、主对话区）完全不动。

## 卡片结构

| 卡片 | 默认 | 内容来源 | 展开规则 |
|---|---|---|---|
| 插件 | 展开 | 官方导航（DOM 原样搬入）+ DS Bot | — |
| 一周会话 | 展开 | 最近 7 天内创建的会话（缺失创建时间时退回最近更新时间） | 全量展开，按「今天 / 昨天 / 本周」分组 |
| 置顶会话 | 收起 | 所有工作区的置顶会话 | 一次 10 条 + 「显示更多」 |
| 自动化任务会话 | 收起 | 有**启用中**自动化任务的会话（同一会话多条任务只出现一次） | 一次 10 条 + 「显示更多」 |
| 工作区 | 展开 | 官方工作区（保留原 3 个图标：搜索 / 视图 / 新建，最右为收起箭头） | 最近点击的 2 个展开，每个前 15 条 + 「显示更多」 |

同一会话可同时出现在多张卡里（按需求允许重复）。

## 视觉规格

- 卡片标题行：高 **30px**、标题 **15px / 700**、右侧收起箭头
- 标题行质感：默认 **08 磨砂玻璃**（半透明白 + `backdrop-filter: blur(6px)` + Above The Sky 灰底 + 1px 亮边/内折射亮线）；**选中卡（当前打开会话所在的那张）切到 05 混凝土**渐变，用于指示当前上下文
- 卡片间距 **6px**、圆角 8px、内容白底
- 会话行高 30px、标题 13px、时间 11px；工作区标签（10px）只在「平铺视图」显示，一周/置顶/自动化三张汇总卡不再显示，避免杂乱
- 工作区名称 13px / 600（标题比它大 2px）
- 卡片宽度为容器宽度 −4px 并水平居中

## 交互

- 点会话 → 打开会话；点工作区行 → 展开/收起并记入「最近 2 个」
- 卡片标题行吸顶（滚动时保持在顶部），折叠状态记在 localStorage（`dsh.sidebarCards.v2.*`）
- 会话行右键/菜单：置顶、取消置顶、归档、取消归档、复制会话 ID
- 卡片标题行 3 个图标：搜索（点击自动展开本卡，按标题/目录实时过滤并显示命中数，回车/ESC 生效）、视图选项（分组 / 平铺 / 显示归档）、新建工作区
- 每个工作区行右侧**只保留一个「＋」= 在該工作区新建会话**（搜索/视图不放到行上）
- 「最近点击的 2 个工作区展开」为严格规则：点第 3 个会收起最早的那个
- 会话可拖拽排序（工作区内，写入 `insertSessionBefore`）
- 空卡片自动隐藏（置顶 / 自动化无内容时不显示）

## 数据来源

- 工作区、置顶集合：官方 Remote `workspace.follow` 实时流
- 会话：官方 Remote `session.list({})`
- 自动化任务：官方 Remote `schedule.list({ active: true })`
- 兜底：Host 半边自建 HTTP（`/sidebar-cards/data`），浏览器侧拿不到鉴权时自动跳过

## 安装 / 卸载

```powershell
# 安装（在 DSH 里让 Agent 执行，或手动）
# plugin_manager install_bundle -> <本仓库目录>

# 停用（恢复官方侧栏，重启后生效）
# plugin_manager set_plugin -> target: include:dsh-sidebar-cards, enabled: false
```

停用后：把官方导航 / DS Bot 搬回原位 → 官方浏览区重新渲染。localStorage 里的 `dsh.sidebarCards.*` 键不会影响官方 UI，可手动清除。

## 已知限制

- 会话创建时间缺失时「一周会话」用最近更新时间代替（DSH 会话列表接口默认不带 createdAt）
- 官方导航与 DS Bot 是 DOM 搬移实现（保留原行为），若官方大幅改版需重新核对
- 未做虚拟滚动；会话很多时首次渲染稍慢（工作区默认每区 15 条，可「显示更多」）
